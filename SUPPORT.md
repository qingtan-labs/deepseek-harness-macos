# Support

Support is provided through [GitHub Issues](https://github.com/qingtan-labs/deepseek-harness-macos/issues).

Before opening an Issue:

1. Confirm that you are using the latest release.
2. Read the [installation guide](docs/installation.md) and [troubleshooting guide](docs/troubleshooting.md).
3. Refresh service status from the menu bar and copy diagnostics if relevant.
4. Remove credentials, usernames, private paths, and unrelated browser information before posting.

Choose the Bug report or Feature request template. Include the Mac model/architecture, macOS version, app version, saved opening method, browser name, what you expected, and exact reproduction steps.

Do not use public Issues for vulnerabilities. Follow [SECURITY.md](SECURITY.md) instead. This project has no private email support, paid support, or guaranteed response time.
